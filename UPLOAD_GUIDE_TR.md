# GitHub'a yükleme — NLPTRIO

1. GitHub hesabına giriş yap: https://github.com/new
2. Repository name: `NLPTRIO-Turkish-Euphemism-Detection`
3. Public veya hocanın erişebileceği Private seç; **Initialize this repository with a README** işaretleme. Lisans seçme; `.gitignore` de ekleme, pakette zaten var.
4. `Create repository` butonuna bas.
5. Bu ZIP dosyasını **önce bilgisayarında bir klasöre çıkart**. GitHub'a ZIP dosyasını değil, içindeki `README.md`, `.py`, `.ipynb`, `nlptrio_results` klasörü vb. içeriği yükle.
6. Boş repo sayfasında `uploading an existing file` bağlantısını aç veya `Add file > Upload files` yolunu kullan.
7. Çıkardığın klasörün **içindekileri**, özellikle `nlptrio_results/` klasörünü sürükleyip bırak.
8. Commit message: `Add mid-project code and measured results`; `Commit changes` butonuna bas.
9. Repo ana sayfasında README görünüyorsa ve `nlptrio_results/baseline_summary.json`, `berturk_runs.json` dosyaları açılıyorsa kontrol başarılı.
10. Repo URL'sini Team13_MidProject sunumundaki Project Card 12 / Reproducibility kısmına yaz.
11. İki takım arkadaşını repo Settings > Collaborators (veya Collaborators and teams) > Add people bölümünden davet et; repo public ise davet yazma yetkisi içindir.
12. **Güncel nihai PDF'i** her öğrenci ayrıca Teams'e yüklemeli. Repo linki tek başına teslim yerine geçmez.

ÖNEMLİ: Şifre, Colab tokeni veya öğrenci numarası olan proposal PDF'i gibi gereksiz kişisel dosyaları public repoya koyma. Bu pakette eski PDF taslağı yoktur.
